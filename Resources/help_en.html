Desktop Profile Manager – Help & User Guide

Desktop Profile Manager is a menu bar app for macOS that lets you save complete work environments as profiles and restore them with a single click: desktop icon positions, hidden icons, wallpaper, launched apps including window positions, and various system settings, including browser tabs.

The app has no Dock icon. You operate it solely via the icon in the macOS menu bar at the top right. Click it to open the menu.

Getting started

  • Launch the app – the icon appears at the top right of the menu bar.
  • Arrange your desktop icons as desired.
  • Choose Settings › Save profile › New profile ….
  • Set a name and emoji, select the contents, and save.
  • Later, restore the profile via the menu or the widget with a click.

Required permissions

For full functionality the app needs the Accessibility permission (System Settings › Privacy & Security › Accessibility). It is required to read and restore window positions/sizes and to show/hide apps.

On first use of these features, macOS automatically asks for permission. Without it, icon positions, wallpaper, and app launching still work – only exact window restoration does not.

For browser tabs, macOS may additionally request Automation permission for Safari, Google Chrome, or Microsoft Edge. This permission is needed to read and reopen tabs.

Supported browsers: Safari, Google Chrome, and Microsoft Edge. Firefox is not supported because it does not provide a reliable public AppleScript interface for saving and restoring tabs.

The menu at a glance

From top to bottom the menu consists of:

  • Profile quick selection – all profiles for direct restoring.
  • ⚙️ Settings – the large submenu with all functions.
  • Help – opens this guide.
  • About Desktop Profile Manager – version and license info.
  • Quit – close the app.

Profile quick selection

At the very top of the menu are all saved profiles, each with a ▶︎ symbol, the chosen emoji, and the profile name.

  • Clicking a profile restores it immediately.
  • The active profile is highlighted in color.
  • With shortcuts enabled, the key combination is shown on the right (e.g. ⌘⌃1).

Settings

All of the following items are located in the ⚙️ Settings submenu.

💾 Save profile

  • New profile … – Opens the profile creation window (name, emoji, contents, optional Wi-Fi assignment and app selection).
  • Overwrite: <profile> – Saves the current desktop state into an existing profile, keeping its previous settings.
Profile names may contain letters, numbers, spaces, hyphens, and underscores. A new name must not already exist; use “Overwrite” or “Edit profile” to update an existing profile.

🔄 Restore profile

Lists all profiles. A click restores the chosen one – identical to the quick selection above, just bundled in a submenu.

👁 Show/hide desktop icons …

Opens a window listing all items on the desktop. For each entry you decide whether the icon is visible or hidden. The state can become part of a profile. When hiding an icon, the app disables Finder's system-wide display of hidden files so the icons do not remain visible in a dimmed state.

🚀 Select apps for profiles …

Opens a window with all running apps and defines a global exclusion list: checked apps are not captured when saving new profiles.

🧩 Show profile widget

Shows a freely movable widget with one button per profile.

  • Borderless and transparent – only the buttons are visible.
  • Movable by dragging; the position is saved.
  • The active profile is highlighted; visibility persists across restarts.

🔳 Compact widget (emojis only)

Switches the widget between normal view (emoji + name) and compact view (large emojis without text, name as tooltip).

⏱ Auto restore

Main switch for the time-based, recurring restoration. When on, a timer repeatedly applies the chosen auto-restore profile at the set interval.

Note: This switch only controls the interval timer. Restoring at login and after sleep are independent and are controlled by the separate switches “🔁 Restore icons at login” and “😴 Restore after sleep” – these work even when auto restore is off.

🧩 Auto restore desktop icons only

Defines what the automatic restoration (interval timer, login, sleep) applies. Off (default): the full profile including wallpaper, apps and system state. On: only the desktop icon positions. Manual restoring via the quick menu is not affected.

⏰ Interval

Defines how often auto restore runs (5–240 minutes). The active value is marked with a checkmark.

📋 Auto-restore profile

Determines which profile is used for automatic restoring, at login, and after sleep. Choose “(None)” to clear the selection – no automatic restoration will then take place.

✏️ Edit profile

Opens the edit window for the chosen profile. Important:

  • Saved icon positions, hidden icons, and wallpaper are preserved – the desktop is not re-captured.
  • Only name, emoji, Wi-Fi assignment, app selection, system states, and content options are changed.
  • Profiles can also be renamed here; associated time and Wi-Fi rules are updated too.

🗑 Delete profile

Permanently removes the chosen profile after a confirmation prompt. This cannot be undone.

📤 Export profile

Saves the chosen profile as a .json file at a location of your choice – for backup or sharing.

📥 Import profile …

Loads a previously exported .json profile file and adds it to your profiles.

Restore switches

  • 🔁 Restore icons at login – Applies the auto-restore profile at login.
  • 😴 Restore after sleep – Restores after the Mac wakes from sleep.
  • 🖼 Restore wallpaper too – Also sets the saved wallpaper.
  • 🚀 Launch apps on restore – Launches the saved apps and restores their windows.
  • 🙈 Hide other apps when switching – Hides non-profile apps (like ⌘H) without quitting them.
  • ⛔ Quit other apps when switching – Quits non-profile apps (caution: unsaved work may be lost).
Note: Hide and Quit are mutually exclusive in practice – usually choose at most one of them.

⏳ App launch delay

Sets the pause between launching individual apps (None to 5 seconds). A larger delay relieves the system when launching many programs.

🔓 Start at login

Sets up a LaunchAgent so the app starts automatically when you log in. The switch is shown as on only when macOS has actually loaded the service; the app displays an error if setup fails.

⌨️ Shortcuts 1–9

Enables global keyboard shortcuts: modifier + keys 1–9 restore the first nine profiles directly – regardless of which app is in the foreground.

⌨️ Key combination

Chooses the modifier for the shortcuts: ⌘⌃, ⌃, ⌥⌘ or ⌃⇧, each with 1–9.

🕓 Auto switch (time/Wi-Fi)

  • Enabled – turns the whole auto-switching on/off.
  • ➕ Add time rule … – Activates a profile at a specific time/time range.
  • 📶 Wi-Fi: set in 'Edit profile' – Set the Wi-Fi assignment per profile in the Wi-Fi name field. When connecting to that network, the profile is activated.
  • Below, active Wi-Fi assignments and configured rules are listed; clicking a rule with the (delete) suffix removes it.

🌐 Language

Sets the interface language: System (follows the Mac), German, or English. This help opens in the selected language.

⬆️ Check for updates …

Checks online whether a newer version is available and shows the result. After confirmation, the DMG is downloaded directly to Downloads and opened. Then drag the app to Applications and restart it. If a release does not contain a DMG file, the app opens its release page instead.

ℹ️ Status line

Display only (not clickable): shows whether auto restore is active and, if so, with which profile and interval.

The profile creation window in detail

  • Emoji field – the symbol before the profile name. The 😀 button opens the macOS emoji picker.
  • Profile name – display name (required).
  • Wi-Fi name (optional) – the profile is loaded automatically when connecting to this network (if auto switch is active).
  • What to save/restore? – icon positions, hidden icons, wallpaper, apps, and browser tabs.
  • Browser tabs (Safari, Google Chrome, Microsoft Edge) – Saves all open web and local file tabs (http(s)://, file://) from currently running supported browsers as well as browser window position and size. On restore the app quits the browser normally and completely, then starts it once with all saved profile tabs. Other apps are cleaned up beforehand. If the browser does not respond to the normal quit within 15 seconds, the switch stops with a warning; the app never force-quits the browser. Supported browsers are Safari, Google Chrome, and Microsoft Edge. Firefox is not supported because its tabs cannot be read or reopened reliably without a browser extension. URLs can contain search terms, internal addresses, or parameters and are stored in the profile. File URLs are captured only for local, absolute paths. Browser window positions require Accessibility permission. Existing profiles must be overwritten once so the browser position is stored separately.
  • System state – dark mode, volume, brightness, Do Not Disturb, Dock, desktop view.
  • App list – which running apps belong to the profile (with Select all).

Frequently asked questions (FAQ)

The app icon is not at the far left of the menu bar.
Hold ⌘ and drag the icon to the desired spot. macOS remembers the position.

An app (e.g. Safari) does not launch on restore.
Apps are launched preferentially via their bundle ID. Make sure Launch apps on restore is enabled.

Window positions are not restored.
Grant the app permission under Privacy & Security › Accessibility.

My browser tabs are not saved or reopened.
Enable Browser tabs (Safari, Chrome, Edge) for the profile, keep the browser open while saving, and enable Launch apps on restore. Also grant the requested Automation permission. Firefox tabs are not captured automatically. On restore the browser is quit normally and restarted with the profile tabs. If a dialog, download, or unsaved content prevents quitting for more than 15 seconds, the app stops without force-quitting it.

The browser window position is not restored.
Grant Accessibility permission and overwrite the profile once while the browser is open. This adds the separately stored browser position to older profiles.

No other profile can be selected while a profile switch is in progress.
Profile items in the menu and widget remain disabled until the current switch has completed. Shortcuts and automatic rules also cannot start a second switch during this time. This prevents browser quit, tab launch, and window restoration operations from overlapping.

The widget is hidden after a restart.
Visibility is saved permanently. Re-enable the widget via Settings › Show profile widget.
